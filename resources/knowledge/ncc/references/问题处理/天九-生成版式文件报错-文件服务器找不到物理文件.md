# 生成版式文件报错：文件服务器找不到物理文件

## 环境

- **项目**: 天九
- **版本**: NCC 2312
- **场景**: 流程阶段[生成版式文件]，流程步骤[待回推]

## 现象

```
流程阶段[生成版式文件],流程步骤[待回推],出现异常:
业务单据版式文件生成接口,执行生成版式文件任务失败,
原因: nc.vo.pub.BusinessException: 生成版式文件失败，失败原因：
主键：1001F11000000032JNXL，类型：F2-Cxx-002 HADC采集:
nc.vo.pub.BusinessException: 生成业务单据其他附件失败:
下载文件(文件路径=8b64f925-a533-40ec-b890-7d5dd4a4b28b)出错，
请检查文件服务配置是否正确
(fs server error, the error message is:
/data/yonyou/tjufs/tjbip/uapattachroot/dde_0/sgk_1/1740542309113_F9E14D8FD850CDC5DB3252935A9D4076.png
(No such file or directory))
```

## 原因

单据（主键 `1001F11000000032JNXL`）关联了附件，`sm_pub_filesystem` 和 `bap_fs_header`/`bap_fs_body` 中有记录，但文件服务器上对应的物理文件已被删除或从未成功写入。

生成版式文件时需要下载附件，文件服务器找不到物理文件 → 报 `No such file or directory`。

## 解决方案

### 方案一：前台删除附件关联

在前台打开对应单据，进入附件管理，删除报错的文件附件后保存。

### 方案二：数据库删除附件关联

```sql
-- 1. 查附件节点信息
SELECT * FROM sm_pub_filesystem WHERE filepath = '1001F11000000032JNXL';

-- 2. 查文件实际存储路径
SELECT b.storepath
FROM bap_fs_header a
INNER JOIN bap_fs_body b ON a.guid = b.headid
WHERE a.path = (SELECT pk_doc FROM sm_pub_filesystem WHERE filepath = '1001F11000000032JNXL');

-- 3. 确认文件确实不存在后，删除附件关联
DELETE FROM sm_pub_filesystem WHERE filepath = '1001F11000000032JNXL';
DELETE FROM bap_fs_body WHERE headid IN (
    SELECT guid FROM bap_fs_header WHERE path = (SELECT pk_doc FROM sm_pub_filesystem WHERE filepath = '1001F11000000032JNXL')
);
DELETE FROM bap_fs_header WHERE path = (SELECT pk_doc FROM sm_pub_filesystem WHERE filepath = '1001F11000000032JNXL');
```

> ⚠️ 数据库操作前先备份相关记录。

## 排查附件文件的 SQL

```sql
-- 查询附件节点信息
SELECT * FROM sm_pub_filesystem WHERE filepath = '单据主键' OR filepath LIKE '单据主键/%';

-- 查询文件头信息
SELECT * FROM bap_fs_header WHERE path = sm_pub_filesystem.pk_doc;

-- 查询文件物理路径
SELECT storepath FROM bap_fs_body WHERE headid = bap_fs_header.guid;
```
