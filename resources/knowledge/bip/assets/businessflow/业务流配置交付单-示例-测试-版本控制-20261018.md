## 5. 业务员验收指引

```text
验什么：销售订单 → 销售发货单 → 销售出库单 → 销售发票

怎么验：
1. 打开「销售订单」，交易类型选「服务交付订单」
2. 单据上应看到「订单发货」按钮
3. 点按钮 → 选择订单 → 应生成「销售发货单」
4. 核对：数量 / 客户 / 组织 / 物料
5. 发货单保存后，继续验「发货出库」「出库开票」

失败先查：
- 看不到按钮：交易类型是否选对 / 流是否启用 / 当前账号有没有按钮权限
- 报「单据上的业务流和下推按钮不一致」：同交易类型是否还有一条生效流
- 生成后字段为空：转换规则映射 / 必填字段 / 来源字段是否有值
- 数量金额不对：回写公式 / 分单字段 / 组织权限
```
