# 唯迈世公有云集成日志不记录请求体、响应体

## 项目信息

| 项目 | 版本 | 环境 |
|------|------|------|
| 唯迈世 | 旗舰版 V5-0403 (YonBIP5.0.2507.SP1) | 公有云 |

## 现象

监控日志里，**请求体的 body 和响应体都不记录**。外系统调用本系统报错时，排查问题拿不出完整日志，无法定位问题。

## 根因

Kafka 认证问题导致集成日志链路追踪失效。集成平台的集成流原本有链路追踪日志，现在不打印了，原来有的日志也不能在链路查看。

## 解决方案

打如下紧急补丁，基于 **V5-0403 合集补丁 (YonBIP5.0.2507.SP1)**。

**补丁依赖**：`YonBIP.5.0.2507_SP20260403-47`

| 模块 | 补丁名称 |
|------|----------|
| API 流 | `YonLinker_iuap-api-stream_iuap.7.0.2507_20250825-7_QP20260416-523` |
| 数据集成 | `YonLinker_iuap-ipaas-dataintegration_iuap.7.0.2507_20250825-7_QP20260416-522` |
| aPaaS 基础 | `aPaaS_iuap-ipaas-base_iuap.7.0.2507_20250824-34_QP20260512-10087` |
| 集成引擎 | `YonLinker_iuap-ipaas-engine_iuap.7.0.2507_20250825-7_QP20260417-524` |
| API 网关 | `aPaaS_iuap-api-gateway_iuap.7.0.2507_20250824-34_QP20260416-9498` |

## 注意事项

1. **补丁安装报错** → 找安装器团队解决
2. **ES 写入数据报错** → 找运维修复 ES 服务
