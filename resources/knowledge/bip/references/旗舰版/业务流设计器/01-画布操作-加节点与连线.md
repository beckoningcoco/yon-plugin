# 画布操作：加节点、连线、选中

> **接单入口**：刚接到业务流任务，先读 `06-接单流程-从任务到确认单.md`；本文是配置阶段的参考。

> 本文所有操作方式都在金隅共享环境实测通过（新建一条业务流，拖入 4 个节点、连 3 条边，保存成功）。

## 一、加节点：从左侧单据树拖到画布

左侧 `.design-menu` 里是要用到的单据（分组：核心单据 / 应用平台 / 财务云 / 供应链云 / 采购云 / 营销云 / 制造云 / 云平台），
每一项是 `.list-item.draggable.is-can-drag.<单据名>.billItemNode`。

### 关键事实：必须用 `mode="mouse"`

**源元素的 `draggable` 属性是 `false`**，这个画布接的是 `mousedown`/`mousemove`/`mouseup`
手势（由 `window.ysDesign` 这个自研拖拽库处理），所以：

```
browser_drag(from="<左侧单据项选择器>", to="<目标>", mode="mouse")
```

`mode="html5"`（默认）**不能作为判据**，尽管它的手势并非完全不生效：实测里它既触发过引擎自己的提示
（「两个单据之间已经存在规则，不能连接」），也真建成过节点和连线；但浏览器不回 `Input.dragIntercepted`，
工具于是报「没有东西可以投递」——**报的结论会和页面事实相反**。看到这句就直接重拖，会得到重复的节点
与重复的连线；先读页面确认，再决定要不要用 `mode="mouse"` 重来。

### 落点由鼠标终点决定，要精确就插探针

`browser_drag` 的 `to` 只接受**元素**，不接受坐标。要落到画布上某个位置，先插一个固定定位的透明探针：

```js
// browser_eval —— 插入探针（用完记得删）
const p = document.createElement('div')
p.id = '__probe'
p.style.cssText = 'position:fixed;left:900px;top:300px;width:10px;height:10px;' +
  'z-index:2147483647;background:transparent;pointer-events:none'
document.body.appendChild(p)
```

然后 `browser_drag(from="<单据项>", to="#__probe", mode="mouse")`，拖完 `document.getElementById('__probe').remove()`。

**落点偏移**：节点左上角会落在鼠标终点**左上方约 (77, 25) 像素**处（实测），要放准就按这个反推探针坐标。
节点落下后可以再拖微调，位置是自由布局，不影响流程语义。

### 移动已有节点

给目标节点加一个临时属性，再用同样的 mouse 拖拽：

```js
// 打标记
document.querySelectorAll('#designer .list-item.ys-node').forEach((n, i) => { if (i === 2) n.setAttribute('data-t', '1') })
```

`browser_drag(from="[data-t='1']", to="#__probe", mode="mouse")`，用完 `removeAttribute('data-t')`。

> ⚠️ **不要用 `by:"text"` 定位节点**。它命中的是节点内部的 `font`/`span`，拖起来会退化成"平移画布"
> （实测两个节点同时偏移几像素）。**一律用 CSS 选择器 + 临时属性**。

> ⚠️ **回报里的元素名不是业务判据**。名字现在取的是"看得见的文字"（隐藏的候选下拉不再混进来，
> 实测报过「ERP销售合同」的那个毛病已修），但它回答的只是"你拖的元素叫什么、手势发去了哪里"，
> **不是"引擎建成了什么"**。**以拖拽之后实测的坐标、节点数、连线数为唯一依据**。

> 回报里还有两条可以用来判断"手势有没有可能落偏"的证据：四个时刻（按下前 / 拖动中 / 松手后 /
> 拖动前基线）指针底下是谁，以及**这一点在不在目标自己的框里**。注意「指针底下不是目标」本身
> 不说明落偏了——透明探针会被 `elementFromPoint` 穿过去、1px 锚点会被外层容器接住，这两种情况
> 工具会明说"指针仍在目标的框里"，不要读成失败；只有它说"这一点确实不在框里"时才是真的偏。

## 二、连线：从源节点 Bottom 锚点拖到目标节点 Top 锚点

### 锚点结构

每个节点内部有一组锚点：

```text
ul.port-list
  └─ li.port-item.Top / .Bottom / .Left / .Right    ← 也是 .ys-endpoint-anchor
        └─ div.port.port-create-node.port-before
        └─ .down-select                              ← 悬停时出现的下拉
```

**锚点的实测样式**：`1px × 1px`、`opacity: 1`、`pointer-events: auto`、`position: absolute`、`z-index: 6`、
背景透明。li 的 id 形如 `billItemNode_<uuid>.Top`。

锚点小到 1px，`browser_drag` 仍然能命中（它按元素中心取点），**不需要**先放大或改样式。

### 连法

```
browser_drag(from="<源节点> li.port-item.Bottom", to="<目标节点> li.port-item.Top", mode="mouse")
```

源节点/目标节点用 `#designer .list-item.ys-node` 加临时属性区分（例如给源打 `data-src="1"`、目标打 `data-dst="1"`）。

### 成功的判据（数数量，不看回报文字）

| 判据 | 值 |
|---|---|
| 源/目标 `.port-item` 是否加上 `ys-connected` 类 | 应出现 |
| 画布内 `.ys-connector-outline` 数量 | **每条边 1 个** |
| 画布内 `.ys-connector` 数量 | **每条边 2 个**（两条 connector svg） |

实测 4 节点 3 边的正确状态就是 `outlines=3, connectors=6`。**用这两个数判断，比看 `browser_drag` 的回报可靠。**

## 三、选中节点与边

### 选中节点

点节点（`#designer span.content-name.ruleItemNode` 或其外层 `.list-item.ys-node`），右侧出现
`.relation-item`，标题「**单据信息**」。

### 选中边 —— 分两种情况

| 边的状态 | 怎么选中 |
|---|---|
| **还没有规则** | 边上会渲染一个 `div.drop-rule-select.ys-overlay`（26×26 的「+」热区），**点它** |
| **已经有规则** | 点连线名 `#designer div.rule-name` |

**这个热区只在没有规则的边上出现**（fieldid 形如 `businessFlowFe_dropruleselect_<边uuid>`）。
配好规则后该边的 overlay 就消失了 —— 所以"找不到那个 + 了"往往说明规则已经配过。

选中后右侧 `.relation-item` 标题「**规则信息**」，里面是推单/拉单/回写三个页签 + 规则卡片
+「+ 新建规则」(`div.relation-add`，内含 `[fieldid="businessFlowFe_designEdge_addBtn"]`)。

规则卡片上的两个操作按钮：**编辑** `[fieldid="businessFlowFe_designEdge_handleItem1"]`、
**删除** `[fieldid="businessFlowFe_designEdge_handleItem"]`。

## 四、左侧单据树怎么搜

`.design-menu input.el-input__inner`（placeholder「搜索」）用 `browser_set_value` 填词后，
`.list-item.billItemNode` 只剩匹配项 —— 比在长树里找快得多。

## 五、底层对象（UI 走不通时的退路，但**优先用真实拖拽**）

画布把这些实例挂在 window 上，必要时可用来查状态：

| 对象 | 是什么 |
|---|---|
| `window.ysDesign` | 拖拽管理库实例：`getManagedElements` / `setPosition` / `getPosition` / `setAbsolutePosition` / `appendElement` / `isElementDraggable` / `setElementDraggable` / `addToPosse` / `deleteConnectionsForElement` |
| `window.ysDesignGraph` | 图形工厂集合：Node / Vertex / Port / Edge / Group / Cluster / Graph |
| `window.ysDesignTool` | 有 `getNodes()` |
| `document.querySelector('div.canvas').__vue__` | 画布组件实例：`initDesign` / `loadData` / `nodeAdded` / `selectBill` / `getBillInfo` / `updateBillInfo` / `edgeTapEvent` / `selectEdge` / `beforeConnect` |

> **注意**：直接改节点 `style.left/top` **未验证是否会回写到数据模型**。位置信息以 DOM / `ysDesign` 为准，
> 要改就用真实拖拽，不要靠改样式。
