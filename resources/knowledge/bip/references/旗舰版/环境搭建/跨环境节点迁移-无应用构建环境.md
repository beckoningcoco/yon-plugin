# 跨环境迁移节点 — 无应用构建环境时的新建节点部署流程

> **项目**：机械总院 BIP 旗舰版 V5 | **场景**：仅生产环境，无应用构建节点

---

## 背景

机械院只有生产环境，没有应用构建（开发）节点。需在另一高版本环境创建节点后迁移过来。

| 环境 | 角色 | 版本 |
|------|------|------|
| 首创环境 | 构建源（有应用构建节点） | 较高 |
| 机械院环境 | 部署目标（仅生产） | 较低 |

---

## 完整流程（12 步）

### 第一步：首创环境 — 新建节点 + 产品包发布

在首创环境的应用构建中新建节点（如"国资委上传"），完成后：

> **产品包管理 → 发布 → 提交到 Git 仓库**

### 第二步：YDS — 拉取产品包代码

```bash
# 在 YDS 工具中切换到产品包对应的分支
git checkout <产品包分支>
git pull
```

拉取后目录中会出现 `camst-script` 目录（产品包提交的代码）。

### 第三步：出盘

> **关键**：只勾选 `camst-script`（产品包代码），**不需要**下载 YonBuilder 脚本。

出盘后检查盘里的 SQL 脚本：
- 搜索节点相关表名
- 看到建表语句（CREATE TABLE）→ 大概率没问题

### 第四步：目标环境安装盘

在机械院安装器中，**产品安装** → 上传盘 → 安装。

### 第五步：配置迁移（源环境导出）

此时目标环境有业务对象，但**菜单和节点入口**还没出现。

在**首创环境**的配置迁移节点：
1. 选中新建的菜单（只需迁移一个菜单）
2. 加入迁移包
3. 导出配置传输包
4. **导出时选择"任意环境部署"**（解决版本差异）

### 第六步：配置迁移（目标环境导入）

在机械院的配置迁移节点导入传输包。
> 环境不一致会导致**校验报错**，这是预期的。

### 第七步：排查校验失败的微服务

看校验不通过的微服务列表。本例中：
- 配置迁移微服务
- PC 工作台微服务

**原因**：机械院版本太低，缺少相关补丁。

### 第八步：查源环境的补丁信息

到**首创环境的安装器**：
> 安装管理 → 点击环境超链接 → 选择产品名称为"应用平台" → 点击详情

### 第九步：找到需要打的补丁

搜索框中输入校验失败的微服务名，查看**制品来源**列：
- 记录下源环境这两个微服务打的补丁制品地址

### 第十步：下载并安装补丁

1. 根据制品来源下载补丁（在线补丁）
2. 到机械院环境安装器：
   > 产品安装 → 上传补丁 → 安装（流程同第四步安装盘）

### 第十一步：⚠️ 沟通重启窗口

> **重要**：安装补丁会导致基础微服务重启，影响系统正常使用。
> 务必与实施人员确认停机窗口！

### 第十二步：验证

重启完成后：
1. **清除浏览器缓存**
2. 重新登录机械院业务中台
3. 检查菜单管理 → 应能看到新节点
4. 检查业务模型管理 → 应能搜到对应业务对象

---

## 流程总结

```
首创环境（高版本）                    机械院环境（低版本）
─────────────────                    ─────────────────
① 新建节点
② 产品包管理 → 提交Git
③ YDS拉取 → 出盘（仅camst-script）
                                      ④ 安装器安装盘
⑤ 配置迁移 → 导出传输包（任意环境部署）
                                      ⑥ 配置迁移 → 导入
                                      ⚠ 校验报错（版本低）
⑦ 查出失败的微服务
⑧⑨ 查源环境补丁 → 下载
                                      ⑩ 安装补丁
                                      ⑪ 沟通停机窗口
                                      ⑫ 重启 → 清缓存 → 验证
```

---

## 关键注意事项

| 注意点 | 说明 |
|--------|------|
| 出盘只勾选产品包 | 不需要 YonBuilder 脚本，避免带多余内容 |
| 配置导出选"任意环境部署" | 否则版本不一致可能导出失败 |
| 补丁安装会重启微服务 | 必须与实施人员沟通停机窗口 |
| 完成后清缓存 | 浏览器缓存可能导致菜单不显示 |
| 版本差异靠补丁弥补 | 源环境版本 > 目标环境时，补丁是桥梁 |
