# 税务档案同步场景规范

## 概述

> **⚠️ 核心场景**：本文件定义税务档案同步的具体业务逻辑

---

## 税务档案同步流程

### 1. 同步触发

| 触发方式 | 说明 |
|---------|------|
| 主动推送 | 第三方系统主动推送税务档案数据 |
| 定时拉取 | 定时任务从第三方系统拉取数据 |

### 2. 数据校验

| 校验规则 | 说明 |
|---------|------|
| 税务编码必填 | tax_code 不能为空 |
| 税率格式校验 | tax_rate 必须是有效的数值 |

### 3. 数据处理

| 操作类型 | 处理方式 |
|---------|---------|
| 新增 | 调用 IYmsJdbcApi.insert() 插入数据 |
| 更新 | 根据 tax_code 查询后调用 IYmsJdbcApi.update() |
| 删除 | 标记为无效，不物理删除 |

---

## 字段映射（动态）

> **⚠️ 重要**：以下字段映射为示例，实际根据外部 Excel/需求文档动态生成

| 第三方字段 | BIP 字段 | 数据类型 | 说明 |
|-----------|---------|---------|------|
| tax_code | taxCode | String | 税务编码（主键） |
| tax_name | taxName | String | 税务名称 |
| tax_rate | taxRate | BigDecimal | 税率 |
| tax_type | taxType | String | 税种 |
| description | description | String | 描述 |

---

## 错误处理

| 错误码 | 说明 | 处理方式 |
|--------|------|---------|
| TAX001 | 税务编码重复 | 返回错误，不执行同步 |
| TAX002 | 税率格式错误 | 记录错误日志，跳过该条数据 |
| TAX003 | 数据格式错误 | 记录错误日志，跳过该条数据 |
