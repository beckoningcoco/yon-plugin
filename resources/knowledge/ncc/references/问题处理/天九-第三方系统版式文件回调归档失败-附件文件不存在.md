# 第三方系统版式文件回调归档失败：附件文件不存在

## 环境

- **项目**: 天九
- **版本**: NCC 2312
- **场景**: 第三方系统版式文件回调归档

## 现象

```
第三方系统版式文件回调归档失败：回调[文件名称]数据不能为空！
回调数据：
ArchFileCallBackRequestDTO.ArchFileInfo(
  billType=GL,
  subjcode=null,
  billId=1001F1100000003FRLOU,
  pkAttachment=1001D110000000AEG5L4,
  fileName=null,
  fileUrl=null,
  fileSize=null,
  outputType=null,
  fileCatalogue=null,
  fileCreateTime=null,
  signature=null,
  signRule=null,
  signTime=null,
  signName=null,
  pkDoc=null
)
【DOC数据已清理】
```

## 原因

与 [[天九-生成版式文件报错-文件服务器找不到物理文件]] 根因相同：

单据（billId=`1001F1100000003FRLOU`）关联了附件（pkAttachment=`1001D110000000AEG5L4`），但服务器上没有该附件的物理文件。

回调归档时读取附件信息，找不到文件 → fileName、fileUrl 全部为 null → 回调校验"文件名称不能为空" → 归档失败。

## 解决方案

### 方案一：前台删除附件关联

在单据上进入附件管理，删除无文件的附件，重新上传后保存。

### 方案二：数据库删除附件关联

```sql
-- 1. 查附件信息
SELECT * FROM sm_pub_filesystem WHERE pk_doc = '1001D110000000AEG5L4';

-- 2. 确认后删除
DELETE FROM sm_pub_filesystem WHERE pk_doc = '1001D110000000AEG5L4';
DELETE FROM bap_fs_body WHERE headid IN (
    SELECT guid FROM bap_fs_header WHERE path = '1001D110000000AEG5L4'
);
DELETE FROM bap_fs_header WHERE path = '1001D110000000AEG5L4';
```

> ⚠️ 数据库操作前先备份。
