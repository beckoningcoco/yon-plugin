# 旗舰版 — 业务规则获取参数

实现 `IYpdCommonRul` 接口，`execute(RulCtxVO rulCtxVO, Map<String, Object> params)` 中获取上下文和单据数据：

> **导包参考：**
> ```java
> import com.yonyou.ypd.bill.basic.service.api.IYpdCommonRul;
> import com.yonyou.ucf.mdd.common.model.rule.RuleExecuteResult;
> import com.yonyou.ypd.bill.basic.vo.RulCtxVO;
> import com.yonyou.ypd.bill.context.BillContext;
> import com.yonyou.ypd.bill.basic.util.CommonRuleUtils;
> ```

```java
public class TransferApplyAuditMesRule implements IYpdCommonRul {

    @Override
    public Object execute(RulCtxVO rulCtxVO, Map<String, Object> params) {

        // 1. 构建单据上下文
        BillContext billContext = new BillContext(
                rulCtxVO.getBillnum(),      // 单据类型
                rulCtxVO.getFullname()      // 实体全名
        );
        billContext.setAction(rulCtxVO.getAction());    // 动作（audit/unaudit）
        billContext.setDomain(rulCtxVO.getDomain());    // 域

        // 2. 获取单据数据
        List<BizObject> bills = CommonRuleUtils.getBills(billContext, params);
        if (CollectionUtils.isEmpty(bills)) {
            throw new BusinessException("ERR-001", "未获取到单据数据");
        }

        // 3. 取第一条单据 + 主键
        BizObject bill = bills.get(0);
        String billId = bill.getString("id");
        if (billId == null || billId.isEmpty()) {
            throw new BusinessException("ERR-002", "未获取到单据ID");
        }

        // 4. 后续查询 + 推送
    }
}
```

## 关键对象

| 对象 | 来源 | 用途 |
|------|------|------|
| `RulCtxVO` | 平台传入 | 获取 `billnum`(单据类型)、`fullname`(实体URI)、`action`(audit/unaudit)、`domain` |
| `Map<String, Object> params` | 平台传入 | 扩展参数 |
| `BizObject` | `CommonRuleUtils.getBills()` | 内存中的单据数据，可通过 `getString("id")` 等取值 |
| `CommonRuleUtils` | 平台工具类 | 获取触发规则的单据 BizObject 列表 |
