# 打上资产包补丁后前台看不到应用菜单

## 现象

资产包平台补丁打上之后，前台不显示 **集成规则、集成日志** 等四个节点。

> 「集成规则」节点位置：应用管理平台 → 实施平台 → 集成实施工具 → 集成规则
> （见 [NCC资产包集成规则配置方法](./NCC资产包集成规则配置方法.md)）

## 快速定位

**用集团管理员账号登录，搜索这几个节点**，按结果分两路：

| 集团管理员能否看到 | 说明 | 去哪一节 |
|---|---|---|
| **能看到** | 只是当前用户/职责的权限没分配 | §2 分配职责权限 |
| **看不到** | 不是职责级问题：或是导入脚本绑错了菜单主键，或是超级管理员没给集团管理员授权模块 | §1 / §3 |

---

## 1. 菜单主键绑错（系统内置菜单 vs 自定义菜单）

系统里可能同时存在**两套菜单**：

- 一套是**系统内置菜单**
- 一套是**自定义菜单**（当前实际在用的）

导入脚本时，如果绑定的菜单主键是**系统内置菜单**的主键，前台就看不到。
→ **应换成自定义菜单的主键。**

## 2. 权限：给职责分配这四个应用

集团管理员账号**能看到**节点时，走这步：

1. 用**集团管理员账号**登录
2. 进入**职责节点**
3. 给该职责分配 **业务全职责** 或 **管理全职责**
4. 把这四个应用（集成规则、集成日志……）的权限一并勾上

## 3. 权限：超级管理员先给集团管理员授权模块

集团管理员账号**自己都看不到**这几个节点时，说明卡在更上一层：

1. 用**超级管理员账号**登录
2. 进入 **集团管理员应用管理** 节点
3. 把对应模块**授权**上
4. 之后再回到集团管理员账号，即可看到

---

## 排查顺序小结

```
集团管理员账号登录 → 搜索这四个节点
  ├─ 有 → 职责节点分配「业务全职责 / 管理全职责」+ 这四个应用权限   （§2）
  └─ 无 → 超级管理员 → 集团管理员应用管理 → 授权对应模块            （§3）
        └─ 授权后仍无 → 查导入脚本绑的菜单主键是否是「系统内置菜单」 （§1）
```
