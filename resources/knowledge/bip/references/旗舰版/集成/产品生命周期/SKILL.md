# 销售订单PLM集成技能

## 单据元数据

> **⚠️ 重要**：以下URI和特征组信息用于调用BIP元数据API

| 类型 | URI | 特征组 |
|------|-----|--------|
| 主表 | cpu-order.deliveryorder.DeliveryOrderVO | deliveryOrderDefineCharacter |
| 子表 | cpu-order.deliveryorder.DeliveryOrderDetailVO | deliveryOrderDetailDefineCharacter |

### 数据访问方式

所有场景均使用 skill `yonbip-c-openapi-integration`（BIP REST API）查询 BIP 数据。

## 业务概述

本技能提供销售订单与PLM（CAPP）系统的通用集成能力，支持将BIP系统中的销售订单数据推送至CAPP进行产品数据管理。

### 核心能力

> **⚠️ 业务流程范围**：仅包含以下步骤

1. **查询销售订单**：从BIP系统查询销售订单数据
2. **销售订单与PLM字段转换**：将BIP字段转换为PLM目标格式
3. **销售订单调用PLM接口**：推送数据至CAPP系统
4. **解析PLM接口返回的数据**：解析响应并回写状态

## 业务场景说明

### 场景1：销售订单推送PLM（CAPP）

- **触发条件**：用户发起销售订单推送请求
- **处理流程**：查询BIP销售订单 → 字段转换 → 调用CAPP创建产品数据 → 解析响应 → 回写状态
- **特殊逻辑**：光电缆组织需过滤已有BOM的订单
