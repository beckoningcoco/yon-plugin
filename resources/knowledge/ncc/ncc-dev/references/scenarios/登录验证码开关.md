# 登录验证码开关（NCC 2111）

## 结论

**NCC 2111 关闭登录验证码是改系统参数，不是改配置文件。**

```
表：     PUB_SYSINIT
参数：   INITCODE = 'randomimg'
名称：   是否启用验证码
取值：   Y = 启用（默认），N = 关闭
```

改完**重启服务**生效（`SysInitQueryForUnlogin` 走参数缓存，不重启可能还是旧值）。

## 操作方式

### 直接改库（最快）

```sql
-- 确认当前值
SELECT initcode, initname, value FROM pub_sysinit WHERE initcode = 'randomimg';

-- 关闭
UPDATE pub_sysinit SET value = 'N' WHERE initcode = 'randomimg';
```

### 前台入口

`PUB_SYSINIT` 对应前台**「参数管理」**节点（功能编码 `102210`），进去找「是否启用验证码」（编码 `randomimg`）。

注意：`sm_funcregister` 里**没有独立的「系统初始化」菜单项**，只有「业务初始化」(10000GI)、「参数管理」(102210)、「参数模板设置」(13050PATP)，所以前台翻不到就直接改库。

## 判断依据（代码链路）

### 前端：登录页决定要不要显示验证码

`hotwebs/nccloud/resources/uap/rbac/login/main/index.<hash>.js`

```js
n.randImg = function() {
    n.props.data.codeVerfiy && ajax({ url: "/nccloud/riart/login/rand.do", ... })
}
```

注意拼写是 **`codeVerfiy`**（NCC 把 Verify 拼成 Verfiy，搜的时候两个都试）。

### 后端：登录校验时判断

`nccloud.web.riart.login.action.LoginVerfiyAction`

```java
UFBoolean cVerfiy = SysInitQueryForUnlogin.getGlobleParaBoolean(LoginConst.PARAM_RAND);
boolean codeVerfiy = cVerfiy != null ? cVerfiy.booleanValue() : false;
if (!codeVerfiy) {
    return ResultProcess.success();      // 不需要验证码，直接放行
}
```

`LoginConst.PARAM_RAND` = `randomimg`，即 `PUB_SYSINIT` 里那条。

### 验证码生成接口

```
URL:  /nccloud/riart/login/rand.do
注册: hotwebs/nccloud/WEB-INF/extend/yyconfig/modules/riart/login/config/action/login.xml
      <name>riart.login.rand</name>
      <label>图片验证码</label>
      <clazz>nccloud.web.riart.login.action.LoginRandAction</clazz>
类:   external/lib/uibaseapp_nccloudLevel-1.jar
```

`LoginRandAction` 只负责生成图片并写 `randimg` cookie，**没有任何开关判断**——不要指望从这里改。

验证码实现链在 `modules/riart/META-INF/lib/riart_riasfbaseLevel-1.jar`：

```
nc.login.bs.ICaptchaService
  → nc.login.bs.impl.CpatchaImpl          （只转发）
    → nc.login.bs.impl.CaptchaInstance     （生成/校验，读写 Redis）
      → nc.login.bs.impl.NumberCaptcha     （数字验证码）
```

同样没有开关，只是执行者。

## 和 NC65 及更早版本的区别

| 版本 | 关闭方式 |
|---|---|
| NC65 / 更早 | `ierp` 目录下的配置文件（所以老经验会去 ierp 找） |
| **NCC 2111** | **`PUB_SYSINIT.randomimg` 系统参数** |

在 NCC 2111 的 `ierp` 目录里翻是找不到的。实测查过：

- `ierp/bin/` 77 个文件（只有 `firstverify-*` / `secondverify-*`，那是**登录验证方式**注册表：`staticpwd`=静态密码、`ncca`=CA 认证，与验证码无关）
- `ierp/sf/loginuiconfig.xml`——登录页外观（背景、图标）
- `ierp/acccheck/`、`ierp/webma/`、`ierp/install/`
- `ierp/bin/prop.xml`——javaHome、数据源、端口
- 数据库 `PUB_VERIFYRULE`——密码策略，空表

## 排查方法（下次遇到类似"某开关找不到"）

1. 前端抓请求，拿到接口 URL（这次是 `/nccloud/riart/login/rand.do`）
2. 在 `hotwebs/nccloud/WEB-INF/extend/yyconfig/modules/{module}/{sub}/config/action/*.xml` 里找到 action 注册，拿到实现类
3. 用 cfr 反编译实现类，看它读什么（`SysInitQueryForUnlogin.getGlobleParaBoolean(...)` 这种就是读系统参数）
4. 参数常量在 `*Const` 类里，对应 `PUB_SYSINIT.INITCODE`
5. 到库里查 `SELECT * FROM pub_sysinit WHERE initcode = '...'`

比在配置文件里盲搜快得多。
