# 场景1：发货单推送

## 概述

> **⚠️ 触发条件**：用户发起发货单推送请求
> **⚠️ 前置条件**：已配置第三方TMS系统

---

## 1. 业务流程

```
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           发货单推送流程                                          │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│  ┌────────────────┐    ┌────────────────┐    ┌────────────────┐                  │
│  │  1.参数校验   │ -> │  2.查询发货单  │ -> │  3.字段转换    │                  │
│  └────────────────┘    └────────────────┘    └────────────────┘                  │
│         │                      │                      │                         │
│         v                      v                      v                         │
│  验证发货单ID         从BIP查询发货         按映射关系转                          │
│  非空               单数据和明细          换目标字段                            │
│                                                                                  │
│  ┌────────────────┐    ┌────────────────┐    ┌────────────────┐                  │

│         │                      │                      │                         │

│  推送数据到          解析返回结果         更新发货单                            │

│                                                                                  │
```

## 3. 配置项

### 3.1 application.properties

```properties
# TMS接口地址
tms.host=http://xxx.tms.com
tms.push.url=/api/order/send
tms.cancel.url=/api/order/cancel

# 鉴权配置
tms.auth.url=/api/auth/token
tms.auth.appKey=your_app_key
tms.auth.appSecret=your_app_secret
```
