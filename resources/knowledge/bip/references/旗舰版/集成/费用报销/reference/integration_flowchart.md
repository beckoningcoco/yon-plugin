## 流程说明

```
┌─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┐
│                                      流程节点说明                                                          │
├─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┤
│  ① 单据录入 (Third → BIP)                                                                          │
│     • 接口: POST /externalpaymentbill/save                                                       │
│     • 参数: _status=Insert, bustype, expensebillDcs.MY_FK_0008(来源单号)                           │
│     • 回调: 同步单据状态 billStatus="CREATED"(待提交)                                                │
│                                                                                                  │
│  ② 保存单据 (BIP)                                                                                │
│     • 调用BIP API创建单据                                                                         │
│     • 返回单据ID和单据编号                                                                        │
│                                                                                                  │
│  ③ 提交单据                                                                                      │
│     • 接口: POST /submit                                                                         │
│     • billStatus: CREATED → SUBMIT                                                                │
│     • 回调: 同步状态 billStatus="SUBMIT"                                                           │
│                                                                                                  │
│  ④ 审核中                                                                                        │
│     • billStatus: SUBMIT → APPROVING                                                                │
│     • 进入审批流程                                                                                 │
│                                                                                                  │
│  ⑤ 审核通过                                                                                       │
│     • 接口: POST /audit                                                                          │
│     • billStatus: APPROVING → APPROVED                                                              │
│     • 回调: 同步状态 billStatus="APPROVED"                                                         │
│     • 触发推送到第三方                                                                            │
│                                                                                                  │
│  ⑥ 结算完成                                                                                       │
│     • 接口: POST /settleDone                                                                       │
│     • payStatus: SUCCESS/FAIL/PART                                                                │
│     • 回调: 同步结算状态 payStatus="SUCCESS"                                                      │
│                                                                                                  │
│  ⑦ 生成凭证                                                                                       │
│     • 接口: POST /createVoucher                                                                  │
│     • voucherStatus: SUCCESS                                                                   │
│     • 回调: 同步凭证状态 voucher.SUCCESS                                                          │
└─────────────────────────────────────────────────────────────────────────────────────────────────────────────────────┘
```

## 状态对应表

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                           单据状态流转                                      │
├────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│   单据状态 (billStatus)              结算状态 (payStatus)                  │
│   ──────────────────────────      ─────────────────────────────────   │
│                                                                          │
│   CREATED   = 待提交              SUCCESS  = 结算成功                   │
│   SUBMIT   = 已提交              PART     = 部分成功                   │
│   APPROVING = 审核中              FAIL     = 结算失败                   │
│   APPROVED = 审核通过            NOT     = 结算中止(止付)               │
│   REJECTED = 审批拒绝                                              │
│                                                                          │
│   ──────────────────────────────────────────────────────────────            │
│                                                                          │
│   凭证状态 (voucherStatus)                                              │
│   ─────────────────────────────                                      │
│                                                                          │
│   WAIT     = 待生成                                                 │
│   SUCCESS = 生成成功                                               │
│   FAIL    = 生成失败                                              │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────────────┘
```

## 回调接口清单

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                           回调接口清单                                    │
├────────────────────────────────────────────────────────────────────────┤
│                                                                          │
│  ① 单据创建回调                                                        │
│     URL: /costControl/billCreated                                       │
│     参数: bipBillId, billNo, billStatus=CREATED                          │
│                                                                          │
│  ② 单据提交回调                                                        │
│     URL: /costControl/billSubmit                                       │
│     参数: bipBillId, billStatus=SUBMIT                                 │
│                                                                          │
│  ③ 审核状态回调                                                       │
│     URL: /costControl/billAudit                                        │
│     参数: bipBillId, billStatus=APPROVING/APPROVED/REJECTED                  │
│                                                                          │
│  ④ 结算状态回调                                                       │
│     URL: /costControl/billSettle                                       │
│     参数: bipBillId, settlementId, payStatus                           │
│                                                                          │
│  ⑤ 凭证生成回调                                                       │
│     URL: /costControl/voucherCreate                                     │
│     参数: bipBillId, voucherId, voucherStatus                         │
│                                                                          │
│  ⑥ 逆流程回调                                                        │
│     URL: /costControl/billReject                                       │
│     参数: bipBillId, billStatus, rejectReason                           │
│                                                                          │
└──────────────────────────────────────────────────────────────────────────────────┘
```
