# BIP 业务流设计器：怎么配置

> 详细手册在参考库里、且**会持续生长**：`bip/references/旗舰版/业务流设计器/`
> 用 `knowledge_search` 找、`knowledge_read` 读；新增的经验直接往那个目录加文档。
>
> 本技能的选择器与数字**都来自真实环境实测**（金隅共享 `dev-fssc.bbmg.com.cn`，2026-10 用 Edge + CDP）。
> 旗舰版各版本主题不同，选择器名可能变；**用之前先用 `browser_eval` 确认一遍结构**，不要照抄当常量。

**一句话分清三层**：业务流 = 「**谁推谁**」（拓扑 + 规则引用）；转换规则 = 「**字段怎么过去**」；
前台 = 「**怎么点**」。业务流画布上一条边只引用一个转换规则编码，规则内容的对错要到转换规则那层查。

## 开工纪律

1. **先分清「预置」和「其他」**：左侧每个云下都有这两个分类。
   **「预置」里的流是平台资产（`isPreset=true`），新增按钮是灰的**；要动手就在**「其他」**下操作。
2. **动预置流之前先说清楚，学习它请只读**（点开面板看、**不点保存**）。要练手就新建一条，练完删掉。
3. **能复用已登录的页面就复用**：先 `browser_targets` 找使用者开着的列表页再 `browser_attach`。
   **点「设计」会 `window.open` 新开页签**，点完要重新 `browser_targets`，别以为点击失败了。
4. **拖拽一律 `mode="mouse"`**：这个画布源元素的 `draggable=false`。`mode="html5"` **不能当判据**——
   实测它的手势进过引擎（引擎弹过自己的提示、也真建成过节点与连线），但工具会因为没拿到
   `Input.dragIntercepted` 而报「没有东西可以投递」，**报的结论与页面事实相反**；看到它先读页面，
   别直接重拖（会得到重复的节点与连线）。要落到精确坐标就先 `browser_eval` 插一个固定定位的
   透明探针 `#__probe`，拖完删掉。
5. **回报的元素名不是业务判据**（名字已改成取"看得见的文字"，隐藏的候选下拉不再混进来）——
   它说的是"你拖的元素叫什么、手势发去了哪里"，**不是"引擎建成了什么"**；
   **以拖后的坐标/连线数/节点数为唯一依据**。定位节点一律用 CSS 选择器 + 临时属性，
   **不要用 `by:"text"`**（会命中节点里的 `font`/`span`，退化成平移画布）。
6. **保存前先确认核心单据的交易类型已设**，否则弹「核心单据的交易类型不能为空」。
   它**只能在规则里设**，节点属性面板的下拉永远是灰的。见 `03`。
7. **判断 `el-select` 选没选上，看容器 `innerText`，不要看 `input.value`**（恒为空串，会误判成没选上）。
8. **动完使用者的流要告诉他改了什么**，不要默默改。

## 常见问题速查

| 现象 | 先查 |
|---|---|
| **「新增」按钮是灰的** | 左侧分类是不是停在**「预置」**上。切到**「其他」**才可新增 |
| **保存弹「核心单据的交易类型不能为空」** | 打开**以核心单据为某一端**的那条规则 → 基本信息 → 设**来源交易类型**或**目标交易类型**。它只能在这里设，节点面板的下拉是 `disabled` 的。设在来源侧或目标侧都能通过校验（实测两种都有），**把核心单据那一端填上即可**。见 `03` |
| **交易类型"选上了"但保存还是报空** | 你看的是 `input.value`（恒为空串）。改看容器 `innerText` |
| **点「设计」之后什么也没发生** | 它是 `window.open` **新开页签**。重新 `browser_targets` 找那个新页签 |
| **拖了单据但画布没反应** | 用了默认的 `mode="html5"`。这个画布要 **`mode="mouse"`** |
| **`mode="html5"` 报「没有东西可以投递」** | 它**不等于页面上什么都没发生**（实测报这句时真的建成过节点和连线）。先读页面再决定要不要用 `mode="mouse"` 重来，别直接重拖 |
| **拖完之后节点出现在别处 / 名字对不上** | 落点由鼠标终点决定（相对节点左上角约偏移 `(-77, -25)`）；要精确就用 `#__probe` 探针。回报的元素名只说明拖的是哪个元素，不代表建成了什么 |
| **回报说「松手没落在落点上」但节点/连线真的建成了** | 一句警告不是结论。若同一行还写着"这一点就在它的框里"，说明指针确实在目标上（探针被穿透、锚点被外层接住都属于这种），不要读成失败 |
| **拖节点变成整块画布平移** | 用 `by:"text"` 命中了节点内部的 `font`/`span`。改用 CSS 选择器 + `data-t` 临时属性 |
| **找不到边上的「+」热区** | `div.drop-rule-select.ys-overlay` **只在还没有规则的边上渲染**。找不到说明这条边已经配过规则了，改点连线名 `#designer div.rule-name` |
| **连线拖了但没连上** | 数 `.ys-connector-outline`（每条边 1 个）和 `.ys-connector`（每条边 2 个）。4 节点 3 边应该是 `outlines=3, connectors=6` |
| **转换规则页只有两三行** | 它是**虚拟列表**（实测 330 行只渲染视口内约 3 行）。要全量就**读接口**，不要 dump DOM |
| **点过「查看全部」后左侧页签全点不动** | 弹窗卡在转换规则页了。**只能点「取消」关掉重开** |
| **下拉里只有一个选项，以为枚举就这些** | 这些 `el-select` / `yy-radio-group` **只渲染当前可用的那一项**，其余是 `<!---->` 占位。枚举要读 **i18n 文案表**（`window.lang.pack` 里 `UID:P_BIZFLOW-FE_*`，实测 984 条），见 `02` 第九节 |
| **想批量看配置 / 抓数据** | 别抠 DOM（虚拟渲染 + 虚拟列表）。用 `flowRule/list`、`getById`、`getRuleByCode` 直接读，见 `04` |
| **`originType` 匹配不上** | 有的带域名前缀（`udinghuo.voucher_delivery`）有的不带（`voucher_order`）。用 `includes`/`endsWith`，或按中文 `originDes`/`targetDes` 匹配 |
| **画布上节点/连线为什么不能连** | 读 i18n 校验文案：`00D8` 核心单据必须是起始单据 / `00DA` 单据自己不能与自己连接 / `00DC` 两个单据之间没有转换规则，不能连线 / `00DB` 两个单据之间已经存在规则，不能连接 / `008D` 分支没有来源单据，无法设置规则 |

## 边界

- 本技能只管**业务流设计器的界面操作与规则参数含义**。**单据转换规则内部的字段映射内容**
  （哪个字段映射到哪个字段、公式怎么写、汇总怎么配）属于转换规则本身的领域，用 `yonyou-bip-dev`。
- 表名、字段名、实体元数据不要靠看页面猜，用 `bip_meta_*` 或 `yonyou-bip-dev`。
- NCC / NC Cloud 是另一条产品线，业务流不是同一套东西，不适用本技能。
