## 5. 业务员验收指引

> 用业务语言写，不出现字段名。下面按实际链路改。

```text
验什么：<销售订单 → 销售发货 → 销售出库单 → 销售发票>

怎么验：
1. 打开「<单据>」，交易类型选「<交易类型>」
2. 单据上应看到「<按钮名>」按钮
3. 点按钮 → 选择来源单据 → 应生成「<目标单据>」
4. 核对：<数量 / 客户 / 组织 / 物料>
5. <配了回写> 保存后，<来源单据> 的「<字段>」应回写为 <预期>
6. <配了分单> 应按 <分组字段> 拆成 <N> 张

失败先查：
- 看不到按钮：交易类型 / 流是否启用 / 按钮权限
- 报「单据上的业务流和下推按钮不一致」：同交易类型是否还有一条生效流
- 字段为空：转换规则映射 / 必填字段 / 来源字段是否有值
- 数量金额不对：回写公式 / 分单字段 / 组织权限
```

## 7. 交付物清单与回滚方式

### 7.1 交付物

| 文件 | 状态 |
|---|---|
| `业务流需求确认单_01.md`（已确认） | `<✅>` |
| `配置快照_03-<流id>-<日期>.json` | `<✅>` |
| `回读记录_03-<流id>.md` | `<✅>` |
| `业务流配置交付单_04.md`（本单） | `<✅>` |
| 验收指引（第 5 节） | `<✅>` |

### 7.2 回滚方式

- **停用**：列表选中 → 停用（`status=false`），配置保留。**首选**。
- **快照**：`配置快照_03-…json` 是改前/交付时的原样；恢复能力未验证，至少可对照重配。
- **删除**：不可恢复，仅用于测试流。
- **改造已有流**：改前快照 + 改后 diff，回退优先停用，不直接删。
